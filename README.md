# J.A.R.V.I.S Web

아이언맨 자비스 느낌의 웹 프로토타입입니다.

## 웹에서 실행 (로컬 URL)
아래 명령을 실행한 뒤 브라우저에서 접속하세요.

```bash
python3 -m http.server 5500
```

접속 URL: **http://localhost:5500**

## GitHub 커밋/푸시 방법
아래 순서대로 실행하면 GitHub에 커밋을 올릴 수 있습니다.

```bash
git add .
git commit -m "feat: update jarvis web"
git push origin work
```

> 브랜치 이름이 `work`가 아니라면 마지막 줄의 브랜치명을 현재 브랜치명으로 바꿔주세요.

## 기능
- 실시간 시계
- 상태 표시(대기/처리 중)
- 채팅형 명령 입력
- 빠른 액션 버튼
- 시간/날짜/계산/추천 응답
